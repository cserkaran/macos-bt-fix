# macos-bt-fix

Keeps Bluetooth mice and keyboards reconnecting on macOS.

When a Mac wakes from sleep, or when you move between desks with the same peripherals paired to more than one machine, macOS sometimes never reconnects to the mouse or keyboard. The fix is always the same: turn Bluetooth off and on again. `bt-fix` does that for you, but only when it is actually needed.

## How it works

A small `zsh` script runs as a launchd agent in the background. It wakes up after login, after every sleep/wake, and whenever Bluetooth is powered on, waits 20 seconds for macOS to reconnect on its own, and then checks the paired device list:

- If a paired mouse or keyboard exists but none of that type is connected, it power-cycles Bluetooth.
- If headphones are connected, it leaves Bluetooth alone so your audio is not interrupted.
- Otherwise it does nothing.

Only devices listed in `~/.config/bt-fix/known` are considered. Anything else that is paired triggers a notification so you can decide whether to add it.

## Requirements

- macOS 13 or later (uses `system_profiler` JSON output and `launchctl bootstrap`)
- [Homebrew](https://brew.sh) and [`blueutil`](https://github.com/toy/blueutil): `brew install blueutil`
- Works on Apple Silicon and Intel Macs; the script finds `blueutil` in either Homebrew prefix.

## Install

```sh
brew install blueutil
mkdir -p ~/.local/bin
cp bt-fix ~/.local/bin/bt-fix
chmod +x ~/.local/bin/bt-fix

# Pair your mouse and keyboard first, then:
~/.local/bin/bt-fix init      # writes ~/.config/bt-fix/known from the paired list
~/.local/bin/bt-fix install   # writes the launchd agent and starts the watcher
~/.local/bin/bt-fix status    # confirm it sees your devices
```

Add `~/.local/bin` to your `PATH` if it is not already there.

## Commands

| Command | What it does |
| --- | --- |
| `bt-fix status` | List paired devices and whether each is connected (default) |
| `bt-fix check` | Power-cycle Bluetooth only if a paired mouse or keyboard type has nothing connected |
| `bt-fix cycle` | Power-cycle Bluetooth unconditionally, then log what reconnected |
| `bt-fix watch` | Run `check` after login, after each wake, and after Bluetooth power-on. This is what the launchd agent runs |
| `bt-fix init` | Write `~/.config/bt-fix/known` from the current paired list. Pass `--force` to overwrite |
| `bt-fix install` | Write `~/Library/LaunchAgents/local.bt-fix.plist` and (re)start the watcher |

## Files

| Path | Purpose |
| --- | --- |
| `~/.local/bin/bt-fix` | The script |
| `~/.config/bt-fix/known` | Bluetooth addresses the script is allowed to act on, one per line, `#` comments allowed. Generated per machine, do not commit it |
| `~/Library/LaunchAgents/local.bt-fix.plist` | launchd agent, generated by `bt-fix install` |
| `~/Library/Logs/bt-fix.log` | Log, rotated daily or at 512 KB, rotated copies kept for 3 days |

## Using the same peripherals on several Macs

Run `bt-fix init` on each Mac separately. Logitech devices with Easy-Switch present a different Bluetooth address on each channel, and Apple devices get a fresh pairing per host, so the known-device list is never the same on two machines.

After re-pairing a device, or switching it to a different channel, run `bt-fix init --force` to regenerate the list.

## Uninstall

```sh
launchctl bootout "gui/$(id -u)/local.bt-fix"
rm ~/Library/LaunchAgents/local.bt-fix.plist ~/.local/bin/bt-fix
rm -r ~/.config/bt-fix ~/Library/Logs/bt-fix.log*
```

## Privacy

The config file and the log contain the hardware addresses of your devices. Both are created with owner-only permissions. Neither needs to leave the machine.
